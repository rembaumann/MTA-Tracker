## Raspberry Pi Models

### ✅ Recommended: Raspberry Pi 4 (4GB or 8GB)

**Why:**
- Fast enough for smooth web browser rendering
- Better for 24/7 operation
- More reliable performance
- Supports dual 4K displays (if needed later)
- Better WiFi and Ethernet performance

**Specs:**
- 4-core ARM Cortex-A72 CPU @ 1.8GHz
- 4GB or 8GB LPDDR4 RAM
- Gigabit Ethernet
- Dual-band WiFi 5
- USB 3.0 ports

**Price:** ~$55 (4GB) or ~$75 (8GB)

### ⚠️ Acceptable: Raspberry Pi 3B+

**Why:**
- Will work but may be slower
- Older architecture
- Less RAM (1GB)
- Slower WiFi

**Price:** ~$35-40

### ❌ Not Recommended: Raspberry Pi Zero

**Why:**
- Too slow for web browser
- Single core processor
- Insufficient RAM
- Poor performance for this use case

## Additional Hardware

### MicroSD Card

**Recommended:**
- **Size:** 32GB minimum (64GB recommended)
- **Speed:** Class 10 or UHS-I
- **Brand:** SanDisk, Samsung, or Kingston
- **Price:** ~$10-15

**Why:**
- Faster boot times
- Better application performance
- More reliable for 24/7 operation

### Power Supply

**Recommended:** Official Raspberry Pi 4 Power Supply (5.1V, 3A)

**Why:**
- Adequate amperage for stable operation
- Prevents undervoltage issues
- Reliable for 24/7 use

**Price:** ~$10-12

**Alternative:** Any quality 5V 3A USB-C power supply (check reviews)

### Case

**Recommended:** Official Raspberry Pi case or quality third-party case

**Why:**
- Protects the Pi
- Some include cooling fans
- Professional appearance

**Price:** ~$10-20

**Options:**
- Official Raspberry Pi case: ~$10
- Cases with cooling fans: ~$15-20
- Custom 3D printed: Variable

### Optional: Cooling

**For 24/7 Operation:**
- **Heatsinks:** ~$5 (recommended)
- **Fan:** ~$10-15 (optional, but good for reliability)
- **Case with fan:** ~$20

**Why:**
- Prevents thermal throttling
- Extends component life
- More reliable for always-on use

## Performance Considerations

### For Smooth Operation:
- **Minimum:** Raspberry Pi 3B+ (may be slow)
- **Recommended:** Raspberry Pi 4 (4GB) - smooth performance
- **Optimal:** Raspberry Pi 4 (8GB) - best performance, future-proof

### Display Refresh:
- The app updates every 30 seconds
- Browser renders smoothly on Pi 4
- Pi 3B+ may have slight lag

### Network:
- WiFi 5 (Pi 4) recommended for reliability
- Ethernet connection preferred for 24/7 use
- Ensure good signal strength if using WiFi
